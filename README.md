# Smart Password Generator

A responsive and user-friendly password generator built using HTML, CSS, and JavaScript. This project allows users to generate secure, customizable passwords with different character combinations and adjustable password lengths.

# Project Overview

The Smart Password Generator helps users create strong passwords for their digital accounts. Users can customize password settings, generate passwords instantly, check password strength, and copy generated passwords to their clipboard.

# Features

- Secure Password Generation: Uses the Web Crypto API for secure random character selection.
- Adjustable Password Length: Generate passwords between 8 and 64 characters.
- Character Customization: Choose from uppercase letters, lowercase letters, numbers, and special symbols.
- Password Strength Indicator: Displays an estimated password strength.
- Copy to Clipboard: Copy generated passwords with one click.
- Input Validation: Displays helpful messages when no character type is selected.
- Responsive Design: Works across desktop, tablet, and mobile screens.
- Clean User Interface: Modern layout with a simple and accessible design.

# How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using the Live Server extension.
4. Click Generate Password to create a new password.
5. Customize the password length and character options.
6. Use the Copy button to copy your generated password.
